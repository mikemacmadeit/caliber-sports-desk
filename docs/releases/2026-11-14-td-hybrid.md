The ordinary/high-value buckets do not double count: ordinary carries exclude inside-five carries; ordinary targets exclude red-zone targets. Receiving TDs are assigned to the recipient. Passing TDs thrown are never an anytime-TD label. Team allocation uses an exact Poisson marginal, `1 - exp(-lambda_player)`, so more simulation trials cannot masquerade as more evidence.

## Train from the real database

The full local football database from the audit is not included in this checkout. Synthetic fixtures exercise the pipeline and timing guarantees only. They are not model evidence.

Install the project's Python dependencies and configure `DATABASE_URL` as the normal application does. Run the CLI against a read-only copy/connection or supply a local JSON export:

```bash
python scripts/train_desk_hybrid.py --league nfl --database \
  --history-start 2016-07-01 \
  --train-end 2024-08-01 --selection-end 2025-01-01 \
  --calibration-end 2026-02-15 --test-end 2026-11-14 \
  --output data/research/hybrid
```

Repeat with `--league fbs`. These dates are an example protocol, not a statement that either league has adequate coverage. Choose and freeze boundaries after inspecting coverage, before examining evaluation outcomes. The trainer refuses periods below 40 team-games or 200 paired player-games and requires both labels. If NFL identity coverage only begins in 2025, use adequate non-overlapping periods within that coverage or wait for more data; do not relabel a training sample as a test.

`--input history.json` replaces `--database`. Accepts `desk_opportunity.COLUMNS` arrays, record dictionaries, or an object with `records` and optional `aliases`. Supply one league only. The database path reuses the measured history loader and canonical team map. It performs SELECTs, no provider requests or data mutations.

Outputs:

- `<league>_desk_hybrid_v1.json`: prediction parameters, provenance, hash, research-only status.
- `<league>_desk_hybrid_v1.report.json`: coverage and separate evaluation; no evaluation labels enter the parameter hash.

The CLI refuses to write directly into the live models directory. After reviewing real-data output and coverage, a valid artifact can be installed at `settings.parquet_dir/models/<league>_desk_hybrid_v1.json` for **comparison only**. Its hash, schema, league, chronology, and calibration must pass the loader. Missing or invalid artifacts leave the incumbent in use. No promotion flag is available.

Live scoring attaches the alternative to `desk_analysis.hybrid`. `freeze_desk_rows` saves paired snapshots through the normal publishing worker. `/v1/shadow/track-record` exposes `hybrid_comparison`. The main Desk choice remains the incumbent's choice. Removing the hybrid artifact stops new comparisons without removing saved evidence.
